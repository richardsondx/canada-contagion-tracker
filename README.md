# Contagion Tracker

The ripple, measured: how Toronto's unaffordability wave travels outward through the corridor. An open-source civic data project by **Richardson Dackam**.

**The full project lives at [Nshipyard/canada-contagion-tracker](https://github.com/Nshipyard/canada-contagion-tracker).**

## What the data shows (StatCan New Housing Price Index, 1981-2026)

- **Kitchener-Waterloo is the epicentre**: new-home prices up 46.7% since 2017 vs Toronto up 2.9%.
- **The corridor front-ran the core**: Hamilton's price cycle correlates 0.87 with Toronto's, but its turning points arrive about 6 months earlier.
- **Toronto is flat since 2017**: index at 102.9 vs 100 in 2017, after peaking at 111.4 in 2022.
